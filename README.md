# منصة عين — حزمة تسليم المشروع

هذي الحزمة تحتوي على كل شي تحتاجه عشان تبدأ (أو تكمّل) بناء منصة "عين" فعليًا في **Claude Code**.

## وين تبدأ؟

اقرأ **`SPEC.md`** أول شي — فيه كل القرارات التصميمية، حقول البيانات، ومنطق كل شاشة، بحالته النهائية. هذا هو الملف اللي تعطيه لـ Claude Code في أول رسالة.

## محتويات الحزمة

```
SPEC.md                     ← المواصفات الكاملة (اقرأه أول شي)
screens/                    ← 9 شاشات React جاهزة (بروتوتايب تصميمي، بيانات تجريبية)
  ain-splash.jsx             الشاشة الترحيبية
  ain-about.jsx               عن الفريق
  ain-dashboard.jsx           الرئيسية
  ain-volunteers.jsx          قائمة المتطوعين
  ain-volunteer-profile.jsx   ملف متطوع
  ain-programs.jsx            قائمة البرامج
  ain-program-profile.jsx     ملف برنامج
  ain-sponsors.jsx            قائمة الرعاة
  ain-sponsor-profile.jsx     ملف راعٍ
brand/
  logo/                      ← شعار عين (SVG + PNG، تركوازي/ذهبي/أبيض-أسود)
  team-logo.png              ← شعار فريق العيون التطوعي (يُستخدم بصفحة "عن الفريق")
presentation/
  ain-intro.pptx / .pdf       ← عرض تعريفي بالمنصة (10 شرائح)
```

## كيف تبدأ المشروع في Claude Code

1. افتح مشروع جديد في Claude Code.
2. ارفع هذا المجلد كامل (أو فك الضغط عنه بمجلد المشروع).
3. أول رسالة تقريبًا كذا:

   > اقرأ ملف SPEC.md وملفات screens/ كمرجع تصميمي. ابنِ لي هذا المشروع فعليًا باستخدام [Next.js / React + قاعدة بيانات SQLite أو Postgres — حدد اللي تفضله]، مع تفعيل الترابط الحقيقي بين الصفحات (المتطوع ↔ البرنامج ↔ الراعي) وقاعدة بيانات حقيقية بدل البيانات التجريبية.

4. Claude Code من هناك يقرأ الملفات ويبدأ يكتب الكود الفعلي.

## ملاحظات مهمة قبل ما تبدأ

- ملفات `screens/*.jsx` هي **معاينة تصميمية بس** (كل شاشة شغالة لحالها ببيانات وهمية ثابتة بالكود) — مو مشروع مترابط. المهمة الأساسية لـ Claude Code هي تحويلها لمشروع حقيقي.
- شعار "عين" المستخدم حاليًا بالشاشات مرسوم كصورة PNG بسيطة (علامة مصمتة بلون واحد بدون تفاصيل داخلية) بعد ما واجهنا مشاكل عرض مع النسخة الأصلية ثنائية اللون. لو تبي الشعار الأصلي (تركوازي/ذهبي بحرف "ع" أبيض)، هو موجود بمجلد `brand/logo/` — بس يحتاج معالجة أدق (SVG حقيقي) عشان يشتغل صح بكل السياقات.
- تفاصيل إضافية (نقاط جُرِّبت وفشلت، قرارات مؤجلة) مذكورة بآخر SPEC.md تحت "ملاحظات للمرحلة القادمة".
